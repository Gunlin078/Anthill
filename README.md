# The Awkward Age

**The Awkward Age** — 2D-платформер для PC с уникальной механикой смены возраста персонажа. Игра разработана в рамках хакатона [LOWREZJAM 2026](https://itch.io/jam/lowrezjam-2026).

**Главная особенность:** В соответствии с правилами джема, игра создана со строгим ограничением разрешения экрана — всего **64х64 пикселя**, масштабированных под современный формат.

---

## Технические требования
* **Версия Unity:** 6000.5.5f1

---

## Как запустить игру?

### Способ 1: Играть в браузере
Вы можете запустить готовую демо-версию на Itch.io:  
[Играть на itch.io](https://offtiex.itch.io/the-awkward-age)

### Способ 2: Запуск исходного кода в Unity
1. Скачайте `.zip` архив репозитория и разархивируйте его.
2. Откройте **Unity Hub** и нажмите кнопку **Add** (или *Add project from disk*).
3. Выберите **папку** с разархивированным проектом.
4. Запустите проект в редакторе Unity.
5. Основная сцена для старта игры находится по пути: `Assets/Scenes/MainMenu.unity` (или укажите точный путь до сцены).

---

* Исходный код и архитектура скриптов находятся в папке: `Assets/Scripts`.
