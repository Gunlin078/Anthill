# Anthill

**Anthill** — 4х-стратегия о муравьиной колонии в духе Civilization V

**Главная особенность:** Core Loop, сочетающий в себе менеджмент ресурсов и пошаговую экспансию. Развивайте свой муравейник, выстраивайте экономику и доминируйте, захватывая соседние колонии.

---

## Игровой процесс (Core Loop)

Игра построена на циклическом и масштабируемом геймплее:
1. **Сбор ресурсов:** Отправляйте рабочих муравьев на поиски еды и строительных материалов
2. **Улучшение колонии:** Создавайте новые и модернизируйте имеющиеся комнаты, открывайте новые виды муравьев и прокачивайте пассивные бонусы
3. **Глобальная экспансия:**  Захватывайте территории соседних колоний войной или дипломатией
4. **Масштабирование:** Каждая захваченная колония увеличивает приток ресурсов, позволяя повысить уровень развития и превзойти конкурентов 

---

## Статус разработки и запуск

**Проект находится на этапе Pre-Alpha (прототипирование).**  
Игра находится на самом начальном этапе создания. На данный момент полноценный вертикальный срез отсутствует. Репозиторий содержит базовые механики и наработки игрового цикла. Билд для игры в браузере пока не доступен.

### Запуск исходного кода в Unity
1. Скачайте `.zip` архив репозитория и разархивируйте его.
2. Откройте **Unity Hub** и нажмите кнопку **Add** (или *Add project from disk*).
3. Выберите **папку** с разархивированным проектом.
4. Запустите проект в редакторе Unity.
5. Основная сцена для старта игры находится по пути: `Assets/Scenes/MainMenu.unity`.
